También prefiero construir proyectos que resuelvan algún problema real en lugar de hacer cosas únicamente para llenar el portafolio.

* 🏋️ Una app para registrar entrenamientos y medir progreso en el gimnasio
* 🎮 Un tracker de League of Legends usando la API de Riot Games
* 🛒 Proyectos full-stack con Next.js, Prisma y PostgreSQL
* 🌐 Sitios web llevados desde el diseño hasta producción

### Cómo me gusta trabajar

Me gusta que el código sea fácil de volver a entender unas semanas después.

Eso normalmente significa mantener componentes enfocados, usar nombres claros, evitar abstracciones innecesarias y no convertir un problema sencillo en una solución demasiado complicada.

Sigo aprendiendo, rompiendo cosas y construyendo otras nuevas.
